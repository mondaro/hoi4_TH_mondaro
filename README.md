# hoi4_thai — ม็อดแปลไทย Hearts of Iron IV

ม็อดแปลภาษาไทยสำหรับ Hearts of Iron IV พร้อมฟอนต์ไทยในตัว ไม่ต้องลงม็อดอื่นเพิ่ม

## มีอะไรบ้าง
- แปลครบทุกไฟล์ภาษาของเกมหลักและ DLC: ระบบ/UI, แผนยุทธศาสตร์, เหตุการณ์, การตัดสินใจ, จิตวิญญาณแห่งชาติ (206 ไฟล์ 116,063 บรรทัด)
- ฟอนต์ไทยในตัว (Noto Sans Thai / Noto Serif Thai) จัดตำแหน่งวรรณยุกต์บนสระไม่ให้ทับกัน
- ชื่อบนแผนที่รองรับภาษาไทย
- ม็อดเสริม `addon/` คืนชื่อประเทศ รัฐ เมือง ภูมิภาค เป็นภาษาอังกฤษ (ใช้เมื่อชื่อบนแผนที่แสดงผลเพี้ยน)

## วิธีติดตั้ง
1. ดาวน์โหลดไฟล์ zip จากหน้า Releases (หรือคัดลอกโฟลเดอร์ `mod/`)
2. แตกไฟล์ไปที่ `Documents\Paradox Interactive\Hearts of Iron IV\mod\hoi4_thai\`
3. คัดลอก `descriptor.mod` ไปไว้ที่ `...\mod\hoi4_thai.mod` แล้วเพิ่มบรรทัด `path="mod/hoi4_thai"`
4. เปิด Launcher แล้วเพิ่มม็อดเข้า Playset

## โครงสร้าง repo
| โฟลเดอร์ | เนื้อหา |
|---|---|
| `mod/` | ตัวม็อดหลัก (localisation + gfx/fonts) |
| `addon/` | ม็อดเสริมชื่อสถานที่ภาษาอังกฤษ |
| `glossary.md` | ตารางคำศัพท์ที่ใช้แปล ให้คำแปลตรงกันทั้งเกม |
| `tools/` | สคริปต์แยกข้อความ ตรวจโค้ดพิเศษ ประกอบไฟล์ |
| `tools/font/` | สคริปต์เพิ่มอักษรไทยลงฟอนต์ของเกม |
| `fonts-src/` | ฟอนต์ไทยต้นฉบับ (สัญญาอนุญาต OFL) |

## เมื่อเกมอัปเดต
1. ใช้ `tools/rest.py` แยกเฉพาะบรรทัดที่ยังไม่ได้แปลจากโฟลเดอร์ `localisation/english` ของเกมรุ่นใหม่
2. แปลไฟล์ `.tsv` ที่ได้ตาม `glossary.md`
3. ตรวจด้วย `tools/check.py` แล้วประกอบด้วย `tools/merge.py` และ `tools/final.py`
